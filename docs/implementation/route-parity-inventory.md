# Original route and workflow parity inventory

Snapshot written **2026-11-03**, based on the 2026-11-02 audit. This is an observed implementation inventory, not a statement that the rewrite is complete.

## Evidence and state boundaries

The user requires equivalent or improved versions of every original public page and admin workflow on the approved new stack. The source baseline is [original route declarations](https://github.com/MikeCy-com/Lefteria-FC/blob/380b4022f0ab0db95fbc52a8613711160a5037a5/frontend/src/App.js#L2270) at full commit `380b4022f0ab0db95fbc52a8613711160a5037a5`. The coordinating audit separately recorded original main `979935267fa2662580579fb33e987b5cc219d969` as a later storage/backend revision; this inventory does not assume that the old checkout proves current production behavior. A fresh compare request for that later commit failed transport during this inventory, so no additional frontend-change claim is inferred from it.

App.js, AdminPanel.jsx, adminNavigation.js, server.py, routes/admin_users.py and organization_scope.py were freshly read through GitHub. The complete recursive GitHub tree had 993 entries and was not truncated. SHA-1 Git-blob hashes for **121** admin UI/backend-route files in the secondary source checkout matched that fresh tree (direct bytes or LF-normalized bytes). Source paths and citations below refer to that pinned GitHub revision.

Rewrite baseline: merged main `b8cd6fcff759059b15272158d5bec29629c20704`. The last separately verified Hostinger UI release is `987ad46a9c6fc1a7d1e992fdee95d399520de688`; the newer public-sections schema/projections were merged in PR21 but were **not** deployed/imported as part of that UI release. Current worktree changes listed as **WIP** are not merged, deployed or browser-verified merely because files exist.

Definitions:

- **Merged route**: a SvelteKit handler/view exists in the reviewed main baseline. It does not establish complete visual or behavioral parity.
- **WIP**: implementation files are present in this task's current worktree. Route-specific tests may pass; production-like data, build, browser, merge and deployment remain separate gates.
- **Missing**: no equivalent handler/workflow exists in the inspected canonical tree. A menu item, generated DTO, permission name or development label does not count.
- **Data**: the base public snapshot contains club/team/group/fixture/published-news projections. A typed public-sections DTO or owner import capability does not prove that its data has been imported.
- **Deployed/browser verified**: requires explicit release and actual hosted/browser evidence, not a local file, passing unit test or HTTP200 alone.

The preceding release recorded 95 hosted page/TLS/authentication checks, with the homepage and normal admin sign-in screen inspected in a browser. It did not establish every original route, every admin capability, real admin login or complete registration/payment behavior. The user's later Academy 500 report remains an explicit defect under investigation at this snapshot. New WIP Academy pages passed focused SSR/loopback-fixture tests; that is not hosted browser verification.

## Source role/permission matrix

The canonical source matrix is [ROLE_PERMISSIONS](https://github.com/MikeCy-com/Lefteria-FC/blob/380b4022f0ab0db95fbc52a8613711160a5037a5/backend/routes/admin_users.py#L56), with organization resolution in [organization_scope.py](https://github.com/MikeCy-com/Lefteria-FC/blob/380b4022f0ab0db95fbc52a8613711160a5037a5/backend/organization_scope.py#L1). This is evidence for preserving or strengthening authority, not permission to copy a weak legacy endpoint. Each migrated operation must check its actual source permission/dependency and current organization/team/group/record ownership.

| Role | Source capability summary |
| --- | --- |
| `super_admin` | `*:*`; user administration and super-only system/security/backup actions remain separately guarded. |
| `manager` | Teams, Academy, fixtures/results/live score/reports, events/attendance, content/messages/wall, finance/shop/facilities/training/marketing; staff read/write/archive/compliance; settings read/write. No `users:*`. |
| `editor` | News/sponsors/gallery wildcards; marketing read; teams/Academy/fixtures read. |
| `marketing` | `social:write` only in this matrix. |
| `coach` | Assigned teams/Academy/training/attendance, assigned-message write, fixtures read. Assignment scope is part of authority. |
| `matchday_editor` | Live-score and match-report wildcards; fixtures and teams read. |
| Unknown/missing role | No permissions. |

The rewrite has tested admin cookie/session/current-grant logic and those role names. That does **not** establish private CRUD, uploads, finance, documents, evaluations, notifications or settings parity.
